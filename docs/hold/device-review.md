# Hold first-device review

Phones currently have **sift-it.8 / code 19**. Hold chrome after that (`b910e15`…`b4e9660`) is on `ui/hold-integration` only — no APK until code **20**. Install a new debug APK over the existing app with the same signing key; do not clear data. Build API is `https://remanence.hryshyn.dev/`. No server deployment belongs to this branch. If Android reports a signature mismatch, stop rather than uninstalling: uninstall loses the device identity and is not a recovery solution.

1. **Entry and scale:** open signed-out Home. Tap anywhere on each soft object. Back out of auth; reopen, sign in, and verify the selected make/open flow resumes once. Missing keys must remain blocked. Check authenticated Home on a compact and a tall phone; leave judgment about spaciousness until seeing it in the hand.
2. **Forms:** login/register switch, wrong password, repeated submit, long handle, lookup offline/not found, explicit recipient acknowledgment and cancel. Open the keyboard in email, password, handle and note; fields scroll, **Sign in** stays above the IME. Wrong password must leave the typed values. Password is masked. Rotate during lookup/confirmation.
3. **Languages:** switch system language EN/RU/UK. Home/headings/common controls use accepted authored copy and DejaVu Sans; older service/error bodies remain English in this pass. Judge wrapping, physical type size and lowercase tone before optical adjustment.
4. **Camera:** deny once, deny permanently, open Settings and return both with and without permission. Only a bound camera enables the shutter. The portrait display uses a 3:4 preview; the existing shared recognition guide remains 2:3. Rotate the phone for the existing landscape alternative. Test the same real portrait and landscape postcards, focus, glare and angle. Never conclude horizontal parity from the UI alone.
5. **Send:** confirm a real recipient, capture front, select 3–5 photos, write a note, publish. Queued is not published. Interrupt network, leave/re-enter, kill/relaunch, check durable upload behavior against the actual outbox. Check server cancellation online/offline/unavailable; received copies are not claimed deleted. Server-side first-open/cancellation work in another dirty worktree is not part of this branch.
6. **Receive:** fresh capture with local materials/offline; no index; recognized with body missing; ambiguous matches; verification failure. Index retry must reuse eligible capture; no private photo appears before the grant. No inbox or grant via deep link.
7. **Open:** the present protocol is still original photos plus note, not a generated collage. Verify full photo is fitted, never cropped. Drag upward and use the about button; image shrinks intact and actual note/content count appears below. Page next/previous while revealed. Close/back, rotate, background, let grant expire, change account. Closing removes private UI immediately, with no exit animation.
8. **Motion and identity:** leave animator duration scale at 1x to judge press. Then set it to zero and confirm pressure still snaps (service must not wait on animation). Remainder uses the measured 0.72 handoff transform so the curved shoulder stays inside the adaptive safe circle — it is **not** bounding-box centred. Inspect the real launcher mask. No artificial splash wait.

Not yet claimable: real matcher results; CameraX timing; keyboard/system-bar behavior; physical legibility; underlayer discoverability; full generated-expression fit/Carry. Those require the phone and the generator artifact contract. Share, fake sender/date and music controls are deliberately absent.
