# Hold first-device review

Phones currently have **sift-it.8 / code 19** (the last shipped APK). Hold chrome after that (`b910e15`…`77b3b38`) plus the feature-committed HOLD-05/06 capture and scan product copy (items 5–6), Astra scan motion, self-addressed capsule open, and the in-app EN/RU/UK language switch is on `ui/hold-integration` only — no APK until code **21 (rc.1)**. Install a new debug APK over the existing app with the same signing key; do not clear data. Build API is `https://remanence.hryshyn.dev/`. No server deployment belongs to this branch. If Android reports a signature mismatch, stop rather than uninstalling: uninstall loses the device identity and is not a recovery solution.

1. **Entry and scale:** open signed-out Home. Tap anywhere on each soft object. Back out of auth; reopen, sign in, and verify the selected make/open flow resumes once. Missing keys must remain blocked. Check authenticated Home on a compact and a tall phone; leave judgment about spaciousness until seeing it in the hand.
2. **Forms:** login/register switch, wrong password, repeated submit, long handle, lookup offline/not found, explicit recipient acknowledgment and cancel. Open the keyboard in email, password, handle and note; fields scroll, **Sign in** stays above the IME. Wrong password must leave the typed values. Password is masked. Rotate during lookup/confirmation.
3. **Languages:** use the in-app switch on Home and Auth (English / Русский / Українська plus System reset): exactly one restart per selection, UI follows without logout, auth, grants, and flow epochs intact. Then switch system language EN/RU/UK. Home/headings/common controls use accepted authored copy and DejaVu Sans; older service/error bodies remain English in this pass. Judge wrapping, physical type size and lowercase tone before optical adjustment.
4. **Camera:** deny once, deny permanently, open Settings and return both with and without permission. Only a bound camera enables the shutter. After switching language, scan still binds once and opens normally (no double session, no lost capture state). The portrait display uses a 3:4 preview; the existing shared recognition guide remains 2:3. Rotate the phone for the existing landscape alternative. Test the same real portrait and landscape postcards, focus, glare and angle. Never conclude horizontal parity from the UI alone.
5. **Send:** confirm a real recipient, capture front, select 3–5 photos, write a note, publish. Queued is not published. Interrupt network, leave/re-enter, kill/relaunch, check durable upload behavior against the actual outbox. Check server cancellation online/offline/unavailable; received copies are not claimed deleted. Server-side first-open/cancellation work in another dirty worktree is not part of this branch.
6. **Receive:** fresh capture with local materials/offline; no index; recognized with body missing; ambiguous matches; verification failure. Index retry must reuse eligible capture; no private photo appears before the grant. No inbox or grant via deep link.
7. **Open (item 7 underlayer is future — not in this code21 pass):** the present protocol is still original photos plus note, not a generated collage. Verify full photo is fitted, never cropped, and that close/back, rotate, background, grant expiry and account change remove private UI immediately with no exit animation. The upward drag, about reveal and content count are item 7 and are **not** in this code21 build; test them only once that lands, and page next/previous only then.
8. **Motion and identity:** leave animator duration scale at 1x to judge press. Then set it to zero and confirm pressure still snaps (service must not wait on animation). Remainder uses the measured 0.72 handoff transform so the curved shoulder stays inside the adaptive safe circle — it is **not** bounding-box centred. Inspect the real launcher mask. No artificial splash wait.

Not yet claimable: real matcher results; CameraX timing; keyboard/system-bar behavior; physical legibility; authored RU/UK capture/scan copy in physical context; full generated-expression fit/Carry. In-app language-switch restart, disposal, and 33+ framework behavior on hardware are open device checks, not unit claims — nothing here is a device PASS. Items 7 (underlayer) and 8 (Carry) are **not** in this code21 (rc.1) pass. RecaptureGuidance is reason-agnostic until the scan state model carries a reason. Share, fake sender/date and music controls are deliberately absent.
